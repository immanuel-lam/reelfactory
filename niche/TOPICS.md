# Topic backlog

Each episode takes the first row marked `todo` (top to bottom), unless the
facts cannot be verified: then mark it `blocked` with the reason and take the
next one. When an episode starts, set its row to `in progress` with the id;
when it passes the review gate and ships, set it to `done`.

Statuses: `todo` (free to take), `in progress` (started, review gate not yet
passed: the next run continues it before anything else), `done` (shipped),
`blocked` (facts could not be verified), `stale` (no longer fits), `redo`
(made once and dropped: never take it by yourself; the owner asks for a
remake).

A good topic passes all four tests:

1. **An everyday object or moment** the audience knows.
2. **A clash**: two things that should not both be true, and the viewer has
   lived the strange part.
3. **A mechanism that can be shown** as a picture, step by step.
4. **A true, sourced answer.** Every step needs a source before scripting.

The score column has one number per test (1 to 5). "Asked" marks phrases
found in real search autocomplete.
